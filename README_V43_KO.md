## 설치
1. ZIP을 압축 해제합니다.
2. GitHub `ohjjunghee-hue/my-signal-ai` 저장소 최상위 폴더에 파일을 올리고 기존 파일을 덮어씁니다.
3. Render의 최신 배포가 Live가 되면 `/api/diagnostics`를 확인합니다.
4. 처음에는 1회 심층 분석이 끝날 때까지 기다립니다.
