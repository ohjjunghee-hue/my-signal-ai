# MY SIGNAL AI PRO V42 — 병렬 분석 및 BUY 탈락 원인 진단

## 실제 추가 기능
- 5/15/60분봉 심층 분석을 종목별로 최대 4개 동시 실행 (DEEP_WORKERS 환경변수 1~8, 기본 4). 빗썸 API 제한에 따라 429가 늘면 2 또는 1로 낮추세요.
- 기존 60초 시세 가속 감시 결과를 심층 분석 대상 우선 선별에 반영. 빠른 가격 상승은 BUY 신호가 아니며 매수 압력의 증거도 아닙니다.
- `/api/diagnostics`에 BUY/PRE/WAIT 건수 및 탈락 사유를 공개. 화면 상단 'BUY 조건 진단' 표시.
- 화면·서버 버전 V42로 통일.
- 기존 연구 엔진, 이력, 차트, 목표가, 지속 후보 기능 보존.

## 배포
1. 압축을 풀고 GitHub 저장소 루트에 파일 업로드(기존 파일 덮어쓰기).
2. Render 최신 커밋 배포 후 `/health`, `/api/status`, `/api/diagnostics` 확인.
3. API 오류가 늘면 Render 환경변수 `DEEP_WORKERS=2` 설정 후 재배포.
4. Render 무료 인스턴스 휴면 및 영구 디스크 미설정 시 지속 기록 손실 가능.

## 한계
이 버전은 REST 기반 병렬 분석이지 WebSocket 실시간 체결/호가 수집이 아닙니다. 급등 사전 포착 성능, 목표가 도달률, 실제 투자 성과는 검증되지 않았습니다. 종목 추천은 연구용 기술 신호이며 자동매매 기능은 없습니다.
