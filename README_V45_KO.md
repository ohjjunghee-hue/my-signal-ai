# MY SIGNAL AI PRO V45 — 실제 관측 성과 검증

## 주요 기능
- V44의 모든 기존 스캐너, 신호 점수, BUY 조건, 병렬 분석, 목표가, 차트, 이력 유지.
- BUY/PRE 신호를 종목·UTC 날짜·신호 종류별 최초 1회 저장. 이후 스캔은 최초 가격을 덮어쓰지 않음.
- 이후 전체 시장 시세 조회마다 관측 현재가 기준 최대/최소 변동률 기록.
- +3/+10/+50%와 최초 손절 관측을 별도 이벤트로 저장. 5분·15분·1시간·24시간·72시간 이후 **첫 관측** 가격을 기록.
- 5분 초과 관측 공백을 경고. 72시간 이후 시세가 없으면 INCOMPLETE 처리.
- `/api/validation`에서 사건별·시간대별 결과와 완료 신호 집계 제공.
- **주의:** 최초 관측 가격과 실제 체결 가격은 다를 수 있음. 서버 휴면 시 고저점 누락, 목표/손절 실제 선후 관계 불확실. 같은 시점 여러 이벤트의 진짜 발생 순서는 알 수 없음. BUY 적합도는 상승 확률이 아님.

## 배포
1. ZIP 압축 해제 후 GitHub 저장소 최상위에 기존 파일 덮어쓰기.
2. Render 배포 완료 확인 후 `/health`, `/api/validation` 확인.
3. 서버 휴면·재시작 중 데이터가 유실되지 않도록 영구 디스크 또는 외부 DB 필요. 기본 SQLite `/data` 경로가 영구 보존되는지 Render 설정에서 확인.
4. 과거 V44 신호를 새 검증 장부로 소급 적중 처리하지 않음. V45 배포 이후 새 신호부터 측정.

## 검증
`python -m unittest discover -p 'test*.py'` 실행. 실거래 성과 검증과 별개.
